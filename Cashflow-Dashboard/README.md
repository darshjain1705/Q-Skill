# Project Cash-Flow Dashboard

A single-page, client-side financial modeling tool for EPC/solar project cash flow —
cost vs. sales curves, working-capital and ROCE sensitivity, invoicing vs. collection
tracking, and scenario comparison, with interactive charts and an exportable summary.

Built during a corporate procurement/finance internship to replace ad-hoc Excel cash-flow
models with an interactive, reusable tool.

> ⚠️ **This is a sanitized portfolio copy.** The real project workbooks (with actual
> contract values, supplier costs, and client names) have been removed. The cost/revenue
> figures baked into the app as defaults have been randomized and project names replaced
> with placeholders ("Demo 300MW Solar Project", etc.) so the tool still runs and charts
> sensibly, without reflecting any real deal's numbers. `sample.xlsx` is a synthetic
> input workbook.

Open `index.html` in a browser to run the interactive model, or `cashflow-dashboard.html`
for the standalone single-file build.
