# Vendor Rating Dashboard

A browser-based procurement dashboard for tracking vendor performance: a 41-parameter
rating matrix, a live world map of vendor locations, team workload views, portfolio KPIs,
and auto-generated scorecard/rating letters — all driven by an uploaded Excel export
(no backend, everything runs client-side).

Built during a corporate procurement internship to replace a manual, spreadsheet-heavy
vendor review process.

> ⚠️ **This is a sanitized portfolio copy.** All real vendor, contact, and purchase-order
> data has been removed or replaced with fictional demo data. `Vendor_Master.xlsx` here is
> a synthetic sample with made-up companies and `@example.com` addresses — bring your own
> export (matching the documented column headers in `docs/`) to use the tool for real.

See `docs/README.txt`, `docs/WORKFLOW.txt` and `docs/SETUP.txt` for how the app is
structured and how to run it (open `vendor_rating.html` in a browser).
